# Styles

One folder per look. A style is a skin over a working film: get the story and timing right in plain
colour first, then apply it. Each folder says what the look is, its rules, and how to apply it, and
points to a worked example.

| Style | Feel | Example |
|---|---|---|
| [one-chain](one-chain/README.md) | Clean SaaS promo, no cuts: lifted UI pieces morph into each other | `studio/src/films/DittoV3.tsx` |
| [riso](riso/README.md) | Risograph print on dark paper, grain, animated on twos; product screens in real colour | `demos/zaps-ditto-riso-v6` |
| [night-reel](night-reel/README.md) | Bold motion-design reel: hard cuts on the beat, flat colour blocks, kinetic type | `demos/showreel` |

A new style: add a folder with a README (feel, palette, type, motion rules, sound, how to apply,
a worked example) and a row here.
