# Kenney one-shots

From Kenney's free packs (https://kenney.nl/assets, licence CC0: free to use, no credit needed),
picked from the "safest" list in latent-spaces/brag `assets/sfx/sfx-analysis.md`.
`scripts/music.py` writes them into `<demo>/music/sfx/` in place of the synthesized ones:

| file | used as | why |
|---|---|---|
| `ui/click2.ogg` → `click2.ogg` | `click` | real button press, low hiss |
| `interface/bong_001.ogg` → `bong_001.ogg` | `pop` | warm soft accent when a thing appears |
| `impact/impactSoft_medium_001.ogg` → `impactSoft_medium_001.ogg` | `land` | warm thud when a card lands |
